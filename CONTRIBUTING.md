# Contributing to Jalte Diye Foundation Projects

Thank you for your interest in contributing to our projects.

We welcome contributions from students, researchers, educators, developers, designers, and community members.

## How to Contribute

### Step 1: Explore the Project

* Read the project documentation.
* Review existing issues and discussions.
* Understand the project's objectives and roadmap.

### Step 2: Select an Issue

You may:

* Pick an existing issue.
* Suggest a new feature.
* Improve documentation.
* Fix bugs.
* Improve testing.

### Step 3: Create a Branch

Use descriptive branch names:

feature/quote-generator

fix/image-rendering

docs/readme-update

### Step 4: Commit Changes

Write meaningful commit messages:

feat: add quote ranking algorithm

fix: resolve image alignment issue

docs: improve installation guide

### Step 5: Submit a Pull Request

Describe:

* What was changed
* Why it was changed
* Any limitations
* Screenshots (if applicable)

## Community Expectations

* Be respectful.
* Be collaborative.
* Provide constructive feedback.
* Document important decisions.
* Follow project guidelines.

## Students and Interns

Students are encouraged to:

* Communicate progress regularly.
* Ask questions early.
* Maintain proper documentation.
* Participate in discussions.
* Review the work of others.

Thank you for contributing to technology for social good.
